## AMD Instinct

<a id="amd-fp6"></a>

### 重点推荐：官方公开 MXFP6／MXFP4 混合训练配方

AMD 的 MLPerf Training 6.1 技术文章说明，FLUX.1 敏感前向使用 MXFP6，反向矩阵乘使用 MXFP4，并通过 Hadamard 旋转、分块缩放与融合量化适配 CDNA4 原生指令。MXFP6 是六比特值配共享缩放；注意力、归一化与通信仍保留 BF16。官方报告评分运行达到质量目标，并公开复现入口；这是新机制与测量公开，不能将跨代 GPU 的整项收益全归给 FP6。

[原始资料](https://rocm.blogs.amd.com/artificial-intelligence/mlperf-training-v6.1/README.html)

<a id="gfx1250-scale"></a>

### PyTorch：gfx1250 补齐 MXFP8／MXFP4／NVFP4 缩放布局

主分支新增 gfx1250 所需的缩放交错布局，支持每 32 元素共享缩放的 MX 格式，以及每 16 元素共享缩放的 NVFP4。关键不只是格式列表：旧的无交错调用在归约维度超过 128 时可能得到错误结果，现在会拒绝不兼容路径。NVFP4 依赖 ROCm 10.0 及以上和新矩阵乘接口；gfx950 使用不同布局，不能照搬。实现含布局及错误路径测试。

[原始资料](https://github.com/pytorch/pytorch/commit/653ca8997b2516d3fbcadd0e7f99c654998ee573)

<a id="atom-cache"></a>

### ATOM 新博客：FP8 缓存还需配合分片与状态复用

11 月 17 日官方机制解读说明，Kimi-K3 的 FP8 潜在缓存与主机缓存、前缀复用、解码上下文并行一起管理，降低长代理会话的显存压力。上下文并行将缓存按 token 分摊到多卡，而不是进一步降低位宽。文章采用八张 MI355X，并明确性能图来自较早的运行；不同并发下的调度与融合内核设置不相同，不宜将汇总吞吐归为 FP8 单项收益。

[原始资料](https://rocm.blogs.amd.com/software-tools-optimization/agentx-atom-serving/README.html)

## NVIDIA 平台与底层算子

<a id="flashattn-pv"></a>

### FlashAttention：MXFP8 前向扩展到概率乘值

继上期查询乘键的 MXFP8 路径，本周原生低精度计算进一步覆盖注意力概率乘值，值张量以每 32 个键共享缩放的方式组织。归一化使用实际量化后概率的和，而对数归一化统计仍来自 FP32 指数和；代码称“exact”并不表示等于未量化注意力。本次核验的合入仅支持非因果前向，排除局部掩码等功能，作者记录了 B200／B300 测试。

[原始资料](https://github.com/Dao-AILab/flash-attention/commit/698323347caa34174154bd39ca8d442ba4b9bf64)

<a id="flashinfer-invariant"></a>

### FlashInfer：MXFP8 激活乘 MXFP4 权重保持批次不变性

新增稠密矩阵乘接口，在显式选择批次不变模式时，使同一输入行的结果不受批大小、行位置和调度配置影响。它在较高激活精度与更小权重存储之间提供一个可复现的组合，覆盖 SM100／103／107。结果仍与架构有关，不是跨 GPU 架构逐位相同；还需满足对齐与缩放布局约束。性能证据属于算子级，不能推断整模型服务收益。

[原始资料](https://github.com/flashinfer-ai/flashinfer/commit/57effe034ded2501c675381ffbd78e44e9057d50)

## Intel GPU

<a id="onednn-prob"></a>

### oneDNN：融合注意力接入 softmax 输出量化

Intel GPU 的融合注意力实现增加概率量化与反量化缩放，把 softmax 输出到后续值矩阵乘之间的精度转换纳入算子描述与内核。相关改动补齐 E4M3 概率舍入及图融合测试，使概率侧低比特语义更明确。当前缩放要求成对提供、采用单个 FP32 标量，GPU 路径使用主机标量；这是主分支底层能力，未给出模型质量或端到端速度结果。

[原始资料](https://github.com/uxlfoundation/oneDNN/commit/7dcb194c614be1e2120dcdfde156d085184df926)
